# LiftRank v1 — Fixed Local Beta

This version has the benchmark data embedded directly inside index.html.

## How to run
1. Extract the ZIP.
2. Double-click `index.html`.
3. Open the Ranks tab.
4. The ranking engine should work without Python, a server, or an internet connection.

## Included
- Workout logger
- Searchable exercises
- Weight/reps set logging
- PR detection + congratulations popup
- Separate Ranks tab
- 1RM or weight+reps ranking input
- Bench Press, Squat, Deadlift and Overhead Press beta ranking
- Bronze → Silver → Gold → Platinum → Diamond → Elite → Legend → Apex
- I → II → III divisions
- Division emoji badges
- Overall score from all entered ranked exercises
- XP and levels
- Profile with PRs and overall rank
- Local browser storage

## Ranking-data note
The current engine is a beta benchmark estimate, not a true global-population percentile. Its compact benchmark anchors are derived from public strength-standard tables and are intended for prototyping only. A later data-engineering pass should replace them with a full, validated empirical reference distribution.
